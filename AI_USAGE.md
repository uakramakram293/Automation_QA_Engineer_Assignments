# AI Tool Usage

I barely used AI for this assignment. I did the test design, risk analysis, and troubleshooting myself. I only used it for small technical help.

**Which AI tool or LLM model did you use, and why did you choose it?**
Claude, through Claude Code. I already had it set up on my machine and it can run commands directly, so it was convenient for quick technical checks.

**How did you use it during the assignment?**
Mainly to run my pytest files and fix an environment problem (pytest wasn't installed, and a plugin conflict was stopping it from running). I also used it once at the end to double-check my answers for anything I might have missed.

**Approximately how much time did you spend using it?**
Not much, maybe 20-30 minutes total, just for the environment setup and the final check.

**Which part of your solution benefited the most from it?**
Getting pytest to actually run properly. That was a small setup issue I didn't want to waste time on myself.

**What was the biggest drawback or limitation?**
It also gave one wrong suggestion during the final check, which I had to catch myself by checking it against the actual assignment instructions.

**How did you validate the AI-generated output before submitting your final answer?**
I ran the tests myself and read the results directly instead of just trusting what I was told. I also checked its feedback against the assignment brief before accepting anything.

**Were there any suggestions from the AI tool that you decided not to use? Why?**
Yes, it said one of my documents was missing a section that was required. When I checked the assignment instructions, that section was never actually required for that assignment, so I ignored that suggestion.

**What part of the final submission best reflects your own independent reasoning?**
Basically everything except the environment troubleshooting: the test scenarios, the risk assessment, and the root-cause analysis in Part 3 are all my own thinking.
